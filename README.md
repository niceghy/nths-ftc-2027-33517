# NTHS Nighthawks Robotics (2026-2027)

GitHub repository containing Team Code that will be utilized by FTC Team 33517 (New Horizons) from Nighthawks Robotics for use in the 2026-2027 season of the FIRST Tech Challenge.

# IMPORTANT FOR CONTRIBUTORS/PROGRAMMERS!
Programmers on this team MUST follow the Standard Operating Procedure for making changes to the code in this repository. They can view this in the [Team SOP Document](https://trello.com/c/6PZccwVY/13-programmers-sop).

# Branch Information
The *master* branch contains the latest files that are stable

The *dev* branch contains the latest files that may or may not be ready for stable use
